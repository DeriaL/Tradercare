# Traders Care: лендінг

Новий лендінг для traderscare.io. Той самий стек, що й у продукті: Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS 3, `motion`, `lucide-react`. Графіки намальовані вручну на SVG, сторонніх бібліотек для чартів немає.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production-збірка, сторінка статична
```

## Структура

```
src/
  app/
    layout.tsx        шрифти Geologica і JetBrains Mono (ринкові дані), метадані, шар зернистості
    page.tsx          порядок секцій
    tokens.css        дизайн-токени (OKLCH), акцент змінюється в рантаймі
    globals.css       база, типографіка, .window / .panel / .glass, слайдер
  components/
    site/             Nav, Footer, DevStill (QA-хелпер, лише в dev)
    sections/         секції сторінки, кожна в окремому файлі
    market/           живий ринок для hero: canvas-рушій графіка (engine.ts), LiveChart, Sessions, Ticker
    previews/         живі мініверсії продукту: Steps (підключення, журнал, розбір)
    ui/               Button, Logo, Reveal, Counter
  lib/
    demo.ts           демо-рахунок: 43 угоди за вересень, з нього рахуються ВСІ цифри на сторінці
    chart.ts          проєкція серій, SVG-лінії
    market.ts         симулятор ринку (seeded), кольори токенів для canvas, торгові сесії з реального годинника
    links.ts          URL продукту (BASE = прод; всередині застосунку поставити "")
    useMedia.ts
    useSafeReducedMotion.ts  reduced motion без розбіжностей гідратації
```

## Секції

Сторінка побудована як одна історія: місяць трейдера від першої угоди до системи. Кожна секція має власну компоновку й власний тип руху.

1. **Hero: живий термінал.** На весь екран іде свічковий графік NAS100 (хвилинні свічки, реплей ×30, демо-дані) з об'ємами, віссю цін, тегом ціни з відліком до закриття свічки і перехрестям з OHLC під курсором. Поверх ринку розігрується угода, як на торговій панелі: лонг зі стопом $500 і ціллю 2R. Ціна йде до стопу, «рука» перетягує стоп нижче, угода закривається на −$760, і графік підписує «ціна відхилення −$260». Наступна угода йде за планом і бере +$1,000. Картка праворуч показує угоду так, як її записує Traders Care. Угорі реальні торгові сесії (Азія, Лондон, Нью-Йорк) з відліком, унизу стрічка демо-котирувань. Під заголовком історія графіка розчиняється.
2. **Платформи**: MT4/MT5, cTrader, Match-Trader, DXtrade.
3. **Маніфест**: абзац читається під час скролу, слово за словом. Три помилки підсвічуються кольором збитку.
4. **Ціна відхилень** (скролі-історія, закріплення на 2-3 екрани): скрол працює як повзунок часу. Обидві криві капіталу малюються угода за угодою прямими відрізками, під ними стовпчики P&L кожної угоди (порушення орхідеєві), кожне порушення лишає маркер із ціною, лічильник збитку росте. Наприкінці місяця правила стають перемикачами, а перехрестя під курсором читає будь-яку угоду.
5. **Як це працює** (горизонтальна доріжка): вертикальний скрол рухає три експонати вбік, як coverflow. Центральний дивиться на тебе, сусіди відвертаються й тьмяніють. На телефоні це нативний свайп.
6. **Воркспейс (bento)**: плитки з'являються хвилею, за курсором усередині плитки йде м'яке світло.
7. **Проп-правила**: денний P&L челенджу малюється наживо на графіку з лініями «Старт дня», «80% ліміту» і «Денний ліміт −$5,000». Коли просадка заходить за 80%, лінія і світло панелі стають орхідеєвими. Під графіком таблиця цілей челенджу з використанням кожного правила.
8. **AI-асистент**: дошка з 43 угод місяця по днях. Після питання дошку «сканує» промінь, потрібні угоди підсвічуються, решта тьмяніє, відповідь друкується великим текстом.
9. **Верифікація**: три картки віялом, яке розкривається при скролі. Картку можна перевернути: на звороті посилання й що в ньому видно.
10. **Розмір позиції**: калькулятор у вигляді одного речення з полями всередині. Результат крутиться, як одометр.
11. **Тарифи** (`#plans`): одна панель на чотири колонки, рядки вирівняні як у таблиці порівняння. Підсвітка переїжджає за курсором.
12. **FAQ**.
13. **Фінальний CTA**: лаймове коло розливається з центру й заливає секцію. Перемикач акцентів перефарбовує заливку.

Скрол інерційний (Lenis), вгорі тонка лінія прогресу сторінки.

## Перенесення в основний застосунок

- Скопіювати `components/sections`, `components/previews`, `components/ui` і `lib/*`.
- Токени з `tokens.css` звести з CARE `tokens.css`. Імена ролей ті самі (bg, surface, ink, muted, profit, loss); акцент лендінгу лаймовий.
- У `lib/links.ts` поставити `BASE = ""`, тоді посилання стануть відносними.
- Шрифт: `Geologica` через `next/font/google`, variable, з cyrillic-підмножиною.

## Якість

- `prefers-reduced-motion`: закріплення вимикаються, усі сцени показують кінцевий стан, Lenis не вмикається, графік hero показує один кадр із завершеною угодою, стрічка котирувань стоїть. Перевірено в Playwright.
- Графік hero тікає лише коли він на екрані й вкладка активна, перемальовується на тіках, а не кожен кадр, і живе на власному шарі композитора.
- Hydration без розбіжностей (сервер і клієнт рендерять однакову розмітку).
- Мобільна версія без горизонтального скролу на 390px; графік «Ціна відхилень» має окрему компактну геометрію.
- `?still` у dev-режимі миттєво завершує всі анімації: зручно для скриншотів у фоновій вкладці.

## Що варто звірити команді

- Тарифи взяті з документації. На поточному сайті Free має 5 рахунків, а Pro працює на Sonnet; у документації Free має 1 рахунок, а Pro працює на Opus.
- Каталог на 15 проп-фірм, способи синхронізації (MetaTrader: пароль інвестора, cTrader: OAuth, Match-Trader і DXtrade: розширення) з документації. MT4 є на поточному сайті, у документації версія MetaTrader не уточнена.
- Усі цифри в прев'ю є демо-даними: у hero графік підписаний «реплей ×30 · демо-дані», стрічка «Демо-котирування», у секції «Ціна відхилень» це теж підписано. Торгові сесії рахуються з реального годинника відвідувача.
- OG-зображення для соцмереж ще не зроблене.

## Свідомі відхилення від документації

- Акцент лаймовий, а не CARE violet (рішення замовника). Profit, loss і warning (орхідея `#C56FE6`) збігаються з CARE.
- Шрифт Geologica замість SF Pro / Inter: краща кирилиця на великих кеглях.
- Лише UA і лише темна тема. У шапці поки немає перемикачів мови й теми, хоча в документації вони є. Для світлої теми потрібен окремий набір токенів і варіант акценту для тексту на світлому фоні.
- У шапці додана кнопка «Почати безкоштовно» поряд з «Увійти».
